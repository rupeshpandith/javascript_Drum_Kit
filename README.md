# JavaScript Drum Kit 🥁

A simple interactive drum kit built with vanilla JavaScript. Press keys or click on the drum pads to play different drum sounds.

## Features

- 9 different drum sounds (clap, hihat, kick, openhat, boom, ride, snare, tom, tink)
- Keyboard support (keys A-L)
- Click/tap support for mobile devices
- Visual feedback with animations

## How to Use

1. Open `index.html` in your browser
2. Press keys **A, S, D, F, G, H, J, K, L** or click on the drum pads to play sounds
3. Create your own beats!

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Audio API

## Installation

Simply clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/rupeshpandith/javascript_Drum_Kit.git
cd javascript_Drum_Kit
```

Then open `index.html` in your preferred browser.
